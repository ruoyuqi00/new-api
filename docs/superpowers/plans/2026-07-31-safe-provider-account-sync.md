# Safe Provider Account Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make repeated Sub2API/provider-account imports refresh credentials without overwriting YuAPI-owned account scheduling and routing settings.

**Architecture:** Keep stable-identity matching and provider credential merging in `model/provider_account_import.go`. Narrow matched-row updates to source-owned fields, while leaving new-account creation unchanged. Surface the backend's existing created/updated/skipped result through the frontend and explain the safe-sync behavior in the import dialog.

**Tech Stack:** Go 1.22+, GORM v2, SQLite/MySQL/PostgreSQL-compatible updates, React 19, TypeScript, TanStack Query, i18next, Bun/Vitest.
