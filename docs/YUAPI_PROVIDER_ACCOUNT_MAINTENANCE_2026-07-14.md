# YuAPI 供应商账号维护能力（2026-07-14）

## 已支持

- 供应商账号表格使用独立滚动区域，支持鼠标滚轮和固定表头。
- 可一键刷新当前筛选结果，选择账号后可只刷新所选账号。
- 批量刷新单次最多处理 100 个账号，服务端并发受控，返回逐账号结果。
- 支持 5、15、30、60 分钟自动刷新；设置保存在当前浏览器中，仅在页面打开且可见时执行。
- 列表会保存并展示最近检查时间、上游 HTTP 状态、上游错误码和错误信息。
- 健康筛选支持正常、限流、认证失败、其他错误和未检查。
- 最近一次成功的用量快照不会被后续失败刷新覆盖。

## 当前适配范围

配额与套餐刷新当前适配 Codex OAuth 账号（账号池适配器类型 57、凭据类型 `oauth_json`）。401/403 时会在存在 refresh token 的情况下先刷新 OAuth 凭据，再重试用量接口；429、订阅失效、凭据拒绝和其他上游错误会按账号记录。

其他账号类型会在批量结果中标记为“不支持”，不会被误判为正常，也不会修改账号启停状态。后续协议适配应继续复用同一批量结果和健康状态契约。

## 运维说明

- 自动刷新与 Sub2API 管理页一致，属于浏览器端定时维护，不是服务器常驻定时任务。
- 批量刷新接口需要渠道操作权限，账号凭据不会出现在列表或批量响应中。
- 本次生产部署仅包含账号维护功能；二次元角色、地球替换及其他视觉试验继续保留在本地分支。
